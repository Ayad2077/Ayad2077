## Featured Projects

### [AMD Equity Research & Valuation Dashboard](https://github.com/Ayad2077/amd-equity-dashboard)

An interactive, full-cycle equity research project covering AMD's financial performance, competitive position, forecasts, valuation, and investment thesis.

**What it includes:**

- Three-statement financial analysis and ratio trends
- Revenue, margin, and segment forecasting
- Discounted cash flow valuation using CAPM-based WACC
- Trading comparables, precedent transactions, and a football field
- Bear, base, and bull scenarios with sensitivity analysis
- Interactive HTML, CSS, JavaScript, and Chart.js visualizations

**Investment conclusion:** BUY recommendation with a **$425 price target** based on the project's May 1, 2026 reference price.
